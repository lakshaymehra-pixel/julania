## Deployment

This is a static website. Deploy on:

- **GitHub Pages** — push to `main` branch, enable Pages in repo settings
- **Netlify** — drag and drop `index.html`
- **Vercel** — import repo directly
- **Any web server** — upload `index.html`

### GitHub Pages Setup
1. Go to repo **Settings → Pages**
2. Source: `main` branch, `/ (root)`
3. Save — site will be live at `https://lakshaymehra-pixel.github.io/julania/`
